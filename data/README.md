# Experimental dataset

The project uses IBM's public Telco Customer Churn sample as the initial ML testbed.

- Expected file: `Telco-Customer-Churn.csv`
- Expected records: 7,043 customers
- Raw variables: 21
- Target: `Churn`
- Data represents a fictional telecommunications company.

Run `python download_data.py` to obtain the source file from IBM's archived public GitHub repository.

The dataset is used for controlled computational experiments. It must not be described as Nigerian customer data.
