# Milestone 2

Copy this ZIP's contents into your existing `rtagc_paper2_starter` folder and replace files when prompted.

Then run:

```powershell
python run_data_quality_experiments.py
```

Send back:
- `outputs/metrics/dq_scenario_metrics.csv`
- `outputs/metrics/dq_rule_results.csv`
- console output

Scenarios cover 5/10/20% missingness, 2/5% duplicate records, invalid contract categories, and negative tenure values.
